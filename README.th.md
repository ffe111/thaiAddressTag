# Thai Address Tagging Notebook

[English](README.md) | ภาษาไทย

ดูว่า NLP ภาษาไทยแบบพจนานุกรมแปลงข้อความที่อยู่ให้เป็นฟิลด์ได้อย่างไรโดยไม่ต้องฝึกโมเดล โน้ตบุ๊กแสดงผลการตัดคำ การแก้คำสะกด และองค์ประกอบของที่อยู่ที่จับคู่ได้ เพื่อให้ตรวจสอบการเปลี่ยนแปลงแต่ละขั้นได้

## สำรวจโน้ตบุ๊ก

เปิด [`address_taging.ipynb`](address_taging.ipynb) บน GitHub เพื่อดูผลที่บันทึกไว้ หรือ [เปิดใน Google Colab](https://colab.research.google.com/github/ffe111/thaiAddressTag/blob/main/address_taging.ipynb) เพื่อทดลอง โน้ตบุ๊กมีเซลล์ทดลองสำหรับ PyThaiNLP หลายเวอร์ชัน ให้เลือกเซลล์ติดตั้งและเซลล์ประมวลผลที่เข้าชุดกัน แทนการรันทั้งหมดเป็นชุดเดียว [`addresses.py`](addresses.py) และ [`hashmap.py`](hashmap.py) เก็บข้อมูลอ้างอิงที่โปรเจกต์ใช้

## สิ่งที่ทำได้และข้อจำกัด

ขั้นตอนประกอบด้วยการทำความสะอาดข้อความ การตัดคำแบบกำหนดเอง การแก้คำด้วยพจนานุกรม และการจับคู่จังหวัด อำเภอ ตำบล และรหัสไปรษณีย์กับข้อมูลอ้างอิง ไม่ได้ทำนายที่อยู่ที่ขาดหายหรือยืนยันว่าส่งของได้ ให้ทดลองด้วยข้อมูลสมมติแทนข้อมูลติดต่อจริง

หากต้องการเรียกผ่าน HTTP ดู [FastAPI รุ่นพจนานุกรม](https://github.com/ffe111/address_detection_api)
